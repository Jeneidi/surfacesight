Catch defects beforethey reach the line.

SurfaceSight fine-tunes a pretrained ResNet18 on MVTec AD bottle images, then proves that an int8 ONNX export stays useful on a normal CPU.

Try the demoSee measured results

Quality inspection is a throughput problem too.

Manual inspection gets tiring when every bottle, part or surface needs the same attention. A useful model must separate acceptable from defective images, fit near the line and expose the mistakes that quality teams need to review.

The benchmark is intentionally honest: MVTec AD is a controlled research dataset, so this demonstrates an inspection method, not production readiness.

Inspection briefAcceptable or defective?

A small transfer-learned classifier for visible bottle defects, with the held-out image and confidence kept in view.

Deployment proofSmaller, measured, repeatable

The same fine-tuned weights are exported to ONNX, quantized to int8 and checked against PyTorch on a fixed sample.

What it does

The pipeline compares a frozen ImageNet feature baseline with a ResNet18 fine-tuned on an 80/20 split. It reports defect F1, median CPU latency, model size, false positives and false negatives.

How it works

Code handles the split, evaluation and export checks. The website only presents the recorded run, so the no-key demo is reproducible without a backend.

  1. Get one category

    Download the bottle portion of MVTec AD, keeping the original license and raw files outside the site.

  2. Learn visual features

    Compare a frozen ImageNet ResNet18 feature baseline with a two-epoch CPU fine-tune of layer 4 and the classifier head.

  3. Protect the holdout

    Use a seeded 80/20 stratified split, then check that the filenames do not overlap.

  4. Compress and check

    Export to ONNX, quantize weights to int8 and compare the ONNX output with PyTorch on a fixed sample.

  5. Show the misses

    Let visitors inspect recorded acceptable and defective examples, including false positives and false negatives.
